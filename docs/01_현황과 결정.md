최종 갱신: 2026-10-02

## 지금 상태 한 장

- **체험판:** 메뉴 20여 개가 실제로 동작한다(만세력 계산, 캐릭터 영상 · 음성, AI 상세 풀이, 자유 상담). 대표 보고용으로 만들었지만 품질이 충분해 그대로 상용화한다.
- **공개 주소:** https://obangsaju.netlify.app (대표 보고 · 테스트용 체험판 모드로 계속 유지)
- **최근 반영(10/1):** PC 화면(양옆 메뉴 · QR, 노트북 겹침 수정), 남성 이용자 대응(태오가 '형'), 공유 시트 통일, 결제 시트 통일(모의 결제), 알림 선택(안드로이드 웹 알림 / 아이폰 카카오톡), 멤버십 새 구성, 작업 원본 GitHub 백업.
- **개발 협의 자료(10/2):** Claude Docs 「오방사주 개발 협의 자료」 — 풀스펙 · 우선순위 · 외부 심사 · 역산 일정 · 어드민 · 가입 혜택 · 오픈 스펙 안.
- **다음 단계:** 이름 확정 → 법인 서류 → 저장소 이전 · 상용 모드 → 로그인 · 서버 · 결제. 상세는 Claude Docs 「오방사주 런칭 로드맵 · 개발 협업 가이드」.

## 결정 기록

- 2026-10-02 · 결제는 한 번 연결 + 서버 상품표 + 구매 기록. 엽전은 크레딧 방식이라 법적 확인 먼저. 로그인은 간편 로그인 여러 개(카카오 · 구글 · 네이버 · 이메일, 애플은 나중).
- 2026-10-02 · 타이트사주 참고: 계정센터 · 기능별 로그인 팝업 · 가입 쿠폰 팝업 · 무료 만세력 · 질문권 · 하단 탭 · 성인 카테고리. AICC에 이메일 상담 추가.
- 2026-10-02 · 어드민 · 슈퍼 어드민 필요. 개발 협의 자료 작성, 11/16 다음 주 오픈(11/24) 안과 12/1 마지노선 제안.
- 2026-10-02 · 정통 신년 두 번째 '소헌 선생의 2027 명리 감정서'(실사 명리가, 하게체), 홈 맨 위 2027 신년 기획전 + 랜딩.

- 2026-10-01 · 11/16 오픈의 중심을 신년운세로. 캐릭터 · 컨셉 · 가격을 달리한 10종(11/16 8종, 12/1 2종) 기획. 실사 명리가 캐릭터는 AI 표시 · 가짜 경력 금지 조건으로 검토.
- 2026-10-01 · 로그인은 필수(간편 로그인 여러 개). '구경은 그냥, 남기려면 로그인'.
- 2026-10-01 · 첫 화면 이름표 '서하의 살롱'(바꿀 수 있음), 서하 소개 시트, 성별 입력, 첫 질문 '오늘은 뭐가 궁금해서 왔어?'.
- 2026-10-01 · 신년운세를 여러 캐릭터가 각자 다른 컨셉으로 풀도록 한다(은주 메모). 같은 사주 계산에 시선 · 말투만 다르게. 런칭 2~3종, 나머지는 12월 신년 성수기. 컨셉은 10/8 확정.
- 2026-10-01 · 타로는 78장으로 확장(일정표 · 체크리스트의 56장 표기 정정).
- 2026-10-01 · 대표 보고용 체험판을 그대로 상용화하기로. 런칭 11월 중순.
- 2026-10-01 · 웹 우선, PC는 가운데 화면 + 양옆 메뉴로 가볍게. 폰 화면은 바꾸지 않음.

- 2026-10-01 · 개발은 은주 + Claude 직접, 개발팀은 결제 · 보안 · AICC 지원. 넷리파이 유지.
- 2026-10-01 · 앱 없음. 구독은 부트페이 정기결제로 진행. 알림은 카카오톡 중심.
