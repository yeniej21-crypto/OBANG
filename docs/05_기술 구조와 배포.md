## 상용 구조(2026-10-02 결정)

- 화면은 지금 체험판 그대로, 공통 코드를 모듈로 묶은 뒤 로그인 · 결제를 붙인다.
- Supabase(서울): 간편 로그인(카카오 · 구글 기본 지원, 네이버는 서버 함수로 별도), 회원 · 프로필 · 보관함 · 상품표 · 구매 기록 · 쿠폰 · 엽전 · 성인 인증 여부. 행 단위 접근 제한(회원은 자기 것만).
- 넷리파이 서버 함수(한 번 60초, 백그라운드 15분): 부트페이 영수증 검증 · 구매 기록, 쿠폰 계산 · 발급, 유료 AI 원고(구매 확인 뒤에만), 카카오 채널 추가 확인, 대시보드 집계. 비밀 키는 서버 환경변수에만.
- 가격은 화면 코드(obpay.js)에 두지 않고 서버 상품표로 옮긴다. 새 메뉴는 상품표 한 줄.
- 유료 풀이의 계산 부분은 아직 브라우저에서 돈다 → 오픈 때는 AI 원고만 서버에서 잠그고, 계산 풀이 서버 이전은 12월.
- 운영 어드민 · 슈퍼 어드민은 같은 사이트의 관리자 전용 화면(/admin). 첫날 모자란 기능은 부트페이 관리자 화면 · Supabase 관리 화면으로 대신.
- 상세: Claude Docs 「오방사주 개발 협의 자료」.

## 배포

1. `tools/check_js.py` 모든 페이지 · 공통 js 문법 검사(실패하면 배포 중단)
2. `tools/build_site.py` proto → export/site(홈을 index.html로, 압축 영상 사용)
3. `tools/deploy_push.sh "메모"` 검사 + 빌드 + main 푸시 → 넷리파이 자동 배포 → `backup.sh` 자동 실행(source 브랜치) → DEPLOYS.log 한 줄
4. claude.ai 체험판: 바뀐 파일만 Artifact publish(`files` 지도, `root`=작업 폴더)
5. 새 환경에서 되살리기: source 브랜치 `tools/restore.sh`

## 테스트 방법

- 헤드리스 크롬(Playwright)으로 폰(390~420폭) · 노트북(1366×657, 1280×585, 1093×520) 크기 화면을 찍어 확인한다.
- 영상은 헤드리스에서 재생이 안 되므로 영상 재생 함수를 건너뛰고 흐름을 확인한다(예: 도화 `playSeq` 대체).

## 주의할 점(겪은 문제)

- 문자열 안에 같은 종류의 따옴표를 넣으면 페이지 전체가 멈춘다(10/1 다음 연애 장애). 배포 전 검사로 막는다.
- 빌드는 export/site를 지우고 다시 만들므로, 로컬 테스트 서버는 빌드 뒤 다시 켠다.
- hanja.js는 화면 글자를 자동으로 바꾸므로, 도장 · 장식 글씨는 `data-hj="0"`으로 제외한다.
- 아티팩트 publish는 그 대화에서 해당 파일을 읽거나 목록을 본 뒤에만 덮어쓸 수 있다.
- 전역 둥근 모서리 금지 규칙 때문에 동그라미는 `border-radius:50%!important`로 써야 한다.
- 홈 `.hIc button` 스타일이 머리 칩을 덮으므로 칩은 `!important`로 덮어쓴다.
- 클래스 이름이 공통 스타일과 겹치지 않게(예: 넘김 표시 `go`가 단추 `.go`와 겹쳐 책 배너가 깨졌음 → `flip`).
