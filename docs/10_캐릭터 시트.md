# 10 · 캐릭터 시트 (살아 있는 목록)

최종 갱신: 2026-10-02 · 규칙: 캐릭터를 새로 만들거나 바꾸거나 확정 · 탈락시키면 그 턴에 이 표를 고친다. 원본 그림 · 영상 작업 ID와 파일 위치가 없는 캐릭터는 "확정"으로 두지 않는다. 생성 이력 · 지시문 전문은 recipes/와 인수인계서, 세계관 설명은 03 · 07.

## 구조

- 태극 → 음양 → 오행: 노을(태극, 갈라지기 전) → 오방신 양의 현신(남신 5) · 음의 현신(여신 5) → 미니 수호신
- 배정은 사주(빈 기운)로. 성별은 대운 계산용으로만 쓰고 캐릭터 · 메뉴 배정에 쓰지 않는다.
- 노출 비중: 정면 = 서하 + 남신 5 / 선택형 = 여신 5(이용자가 고르면 나오는 같은 기운의 다른 얼굴, 특정 메뉴에 붙이지 않음) / 특별 = 경계 캐릭터.
- 그림 · 영상 공통: 입체감 · 원근감 · 실감이 표정 유지보다 우선.
