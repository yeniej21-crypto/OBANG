# 00 · 시작 안내 (새 채팅은 이 문서부터)

오방사주는 녹트서울(UDID 자회사 · 독립법인)이 2026년 11월 16일(월) 웹으로 여는 AI 사주 서비스다. 은주가 기획 · 화면 · 비주얼을 맡고 Claude와 직접 개발한다. 결제 연동은 사내 개발팀이 지원한다.

## 새 채팅에서 이어 하는 순서

1. 이 문서 → `01_현황과 결정` → 할 일에 맞는 문서(02~06)를 읽는다.
2. 할 일 목록과 날짜는 Claude Docs 문서 「오방사주 런칭 로드맵 · 개발 협업 가이드」의 '마스터 플랜 · 전체 체크리스트 · 일정표' 탭이 기준이다. 체크리스트 상태를 먼저 확인한다.
3. 코드 작업이면 GitHub `yeniej21-crypto/OBANG`을 받는다.
   - `source` 브랜치 = 작업 원본(proto · tools · server · HANDOFF.md)
   - `main` 브랜치 = 배포본(넷리파이가 자동 배포)
   - 새 작업 환경에서는 `tools/`의 스크립트 안 경로(SP)를 새 위치에 맞춘 뒤 `check_js.py → build_site.py → deploy_push.sh` 순서로 쓴다.
4. 작업이 끝나면 `작업 인수인계서 (프로토타입)`에 번호를 이어 기록하고, `01_현황과 결정`의 결정 기록을 갱신한다.

## 꼭 지킬 것

- 답은 항상 한국어로.
- 크레딧을 쓰기 전에 계획(대사 · 컷 수 · 예상 크레딧)을 먼저 보여 주고 승인받는다. 크레딧은 아끼되 품질은 낮추지 않는다.
- API 키는 넷리파이 환경변수에만 둔다. 채팅 · 코드 · 문서에 절대 붙이지 않는다.
- 배포 전에는 `check_js.py`로 스크립트 오류 검사를 반드시 돌린다(2026-10-01 다음 연애 화면 장애 이후 추가).
