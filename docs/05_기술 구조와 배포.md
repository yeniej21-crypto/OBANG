## 화면 파일(proto)

- 페이지마다 HTML 한 파일에 화면 · 스타일 · 스크립트가 들어 있다(22개). 홈은 `seoha-salon.html`이고 빌드 때 `index.html`이 된다.
- 공통 스크립트
  - `saju.js` 만세력(절기 시각 1949~2031, 음력 1950~2030), `saju_x.js` 십성 · 신살 등 확장
  - `hanja.js` 한자에 한글 병기, 용어 쉬운 뜻, `HJ.bro()` 남성 호칭 변환
  - `pcshell.js` PC 화면(폭 1060 이상 양옆 메뉴 · QR), `qrgen.js` QR 생성
  - `obshare.js` 공통 공유 시트 · 스토리 카드, `obpay.js` 공통 결제 시트 · 알림 선택
  - `premkit.js` · `premkit.css` 상세 풀이 화면 조각, `premai.js` AI 원고 호출(claude.ai 안에서는 sample, 밖에서는 /api/premai), `prem2.js` · `prem2_core.js` 연애 상세 공통
  - 메뉴별 상세: `*_prem.js`
  - `ask.js` 자유 상담(캐릭터 페르소나 · 서버 /api/chat · 예시 답변)
  - `menuintro.js` 메뉴 진입 캐릭터 영상, `hscroll.js` PC 가로 스크롤, `depth3d.js` 깊이 입체, `reveal.js`, `archive.js` 보관함
  - `free_plus.js` 무료 존 신규 4종, `tarot_data.js` · `tarot_read.js` 타로

## 서버(넷리파이 함수)

| 주소 | 하는 일 |
| --- | --- |
| /api/premai | 상세 풀이 AI 원고(스트리밍), 결과를 넷리파이 Blobs에 캐시 |
| /api/chat | 자유 상담(스트리밍). 첫 메시지에 [사주 사실] 필수, IP당 하루 8개 · 전체 하루 300 · 한 달 4,000 |

- 모델: claude-sonnet-5-5. 키는 넷리파이 환경변수 `ANTHROPIC_API_KEY`에만 있다.
- GET으로 열면 `{ok, key, model}` 진단이 나온다.
- 런칭 전: 키 교체, Anthropic 콘솔 월 지출 한도 설정.

## 배포

1. `tools/check_js.py` 모든 페이지 · 공통 js 문법 검사(실패하면 배포 중단)
2. `tools/build_site.py` proto → export/site(홈을 index.html로, 압축 영상 사용)
3. `tools/deploy_push.sh "메모"` 검사 + 빌드 + main 푸시 → 넷리파이 자동 배포
4. claude.ai 체험판: 바뀐 파일만 Artifact publish(`files` 지도, `root`=작업 폴더)
5. 원본 백업: `source` 브랜치에 proto · tools · HANDOFF를 커밋

## 테스트 방법

- 헤드리스 크롬(Playwright)으로 폰(420×880) · 노트북(1366×657, 1280×585, 1093×520) 크기 화면을 찍어 확인한다.
- 영상은 헤드리스에서 재생이 안 되므로 영상 재생 함수를 건너뛰고 흐름을 확인한다(예: 도화 `playSeq` 대체).

## 주의할 점(겪은 문제)

- 문자열 안에 같은 종류의 따옴표를 넣으면 페이지 전체가 멈춘다(10/1 다음 연애 장애). 배포 전 검사로 막는다.
- 빌드는 export/site를 지우고 다시 만들므로, 로컬 테스트 서버는 빌드 뒤 다시 켠다.
- hanja.js는 화면 글자를 자동으로 바꾸므로, 도장 · 장식 글씨는 `data-hj="0"`으로 제외한다.
- 아티팩트 publish는 그 대화에서 해당 파일을 읽거나 목록을 본 뒤에만 덮어쓸 수 있다.
