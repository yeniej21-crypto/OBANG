## 2. 클링 영상 기본 설정 (지금까지 전부 이 설정)

- 모델: Kling 3.0, 모드 pro, 길이 5초(대사가 길면 7~8초), 화면비 9:16(1080×1920)
- 소리: 켬(대사 영상) / 끔(움직이는 포스터 · 반복 영상)
- cfg 0.5, 프롬프트 자동 보강 끔
- 시작 그림 1장(start image)만 넣는다. 끝 그림은 안 쓴다.
- 크레딧: 5초 소리 켬 약 10. 실패하면 환불된다. 한국 시간 밤늦게는 대기열이 길어 40분 넘게 걸리거나 실패할 수 있다.

## 3. 은주가 Higgsfield(클링) 사이트에서 직접 다시 만드는 법

1. higgsfield.ai 로그인 → 영상 만들기 → 모델 Kling 3.0 선택.
2. 시작 그림: 레시피의 '시작 그림' 주소를 열어 저장한 뒤 올린다. 또는 내 기록(History)에서 그 그림을 찾아 '영상으로'를 누른다.
3. 지시문: 레시피의 지시문 전문을 그대로 붙인다. 대사만 바꿀 때는 따옴표 안 한국어만 바꾸고 목소리 설명은 그대로 둔다(목소리가 같은 사람처럼 나오는 핵심).
4. 설정: pro · 5초 · 9:16 · 소리 켬 · 프롬프트 보강 끔.
5. 같은 지시문이어도 결과는 매번 조금 다르다. 2개를 뽑아 입 모양 · 발음이 맞는 쪽을 고른다.

## 6. 받은 영상 가공(서비스용)

Higgsfield 샌드박스에서 내려받아 아래처럼 줄인 뒤 zip으로 묶어 은주에게 주소를 건넨다 → 은주가 내려받아 대화에 첨부 → proto/v/에 넣는다.

```bash
ffmpeg -i raw.mp4 -vf "scale=720:-2,fps=24" -c:v libx264 -profile:v main -crf 25 -g 48 -pix_fmt yuv420p -movflags +faststart \
  -af "loudnorm=I=-19,afade=t=in:d=0.05,afade=t=out:st=<길이-0.2>:d=0.2" -c:a aac -b:a 96k out.mp4
```

- 무음 반복 영상(포스터)은 540px, crf 27, 앞으로 재생 + 거꾸로 재생을 이어 붙여 끊김 없이 반복(핑퐁).
- 대사는 faster-whisper(small, ko)로 받아써서 맞는지 확인하고, 자막 타이밍은 단어 시각으로 맞춘다.
